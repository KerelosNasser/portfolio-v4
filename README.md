## Running Locally

```bash
# 1. Clone the repository
git clone https://github.com/KerelosNasser/portfolio-v4.git
cd portfolio-v4

# 2. Install dependencies
pnpm install

# 3. Start development server
pnpm dev
```

Visit [http://localhost:3000](http://localhost:3000) to view the site.

### Checks

```bash
# Typecheck
pnpm typecheck

# Lint
pnpm lint

# Production build
pnpm build
```
